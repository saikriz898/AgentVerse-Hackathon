> Production-ready, AI-powered Financial Architect that estimates the total cost of building, deploying, operating, and maintaining software products.

## 🚀 Features

- 📊 **Executive Dashboard**: Real-time financial metrics, KPI cards, interactive Recharts visualizations, cost distribution, and risk alerts.
- 🧮 **AI Project Cost Estimator**: Analyzes 20+ cost parameters (Frontend, Backend, DB, AI APIs, DevOps, QA, Cloud, Security, Maintenance) with confidence scores and reasoning.
- 💼 **Budget Planner**: Allocate and track department budgets, reserve emergency funds, and receive threshold warnings.
- 🔍 **Granular Cost Breakdown**: Itemized financial analysis across Development, Infrastructure, AI Services, DevOps, QA, Deployment, and Maintenance.
- ☁️ **Infrastructure Price Comparison**: Compare cloud costs across AWS, Azure, GCP, DigitalOcean, Vercel, Supabase, Neon, Railway, and Cloudflare.
- 📈 **ROI Analysis & Break-even Calculator**: Investment payback period, net profit calculations, and revenue sensitivity sliders.
- 🔮 **Predictive Forecasting**: 12-36 month expense projections under Conservative, Base, and Aggressive growth scenarios.
- 📄 **Financial Reports & Export**: Download detailed financial reports in PDF, Excel (XLSX), CSV, and JSON formats.
- 🌐 **Multi-Currency Support**: Switch seamlessly between USD ($), EUR (€), GBP (£), and INR (₹).

## 🛠️ Quick Start

### Frontend (React 19 + TypeScript + Vite)
```bash
cd frontend
npm install
npm run dev
```

### Backend (FastAPI + Python)
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Docker Compose
```bash
docker-compose up --build
```
