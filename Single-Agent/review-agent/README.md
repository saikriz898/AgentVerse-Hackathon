## 🌟 Role in the Single-Agent Ecosystem

The **Review Agent** functions as the quality assurance gatekeeper and security scanner for the LifeOS platform. It acts as an automated auditor, ensuring that outputs from all other single agents meet strict schema validity, logical consistency, and security standards before being passed to stakeholders or stored in memory.

---

## 🔄 Inter-Agent Integration Matrix

| Agent Being Audited | Review Agent Evaluation Scope | Approval Threshold |
| :--- | :--- | :---: |
| **🔬 Research Agent** | Verifies citation credibility, checks claim consistency, and flags unverified facts. | Quality Score &ge; 80 |
| **📅 Planning Agent** | Validates task dependency cycles, timeline feasibility, and milestone completeness. | Quality Score &ge; 80 |
| **💰 Finance Agent** | Verifies math calculations, budget allocation boundaries, and currency consistency. | Quality Score &ge; 80 |
| **🧠 Memory Agent** | Audits vector memory tags, importance scores, and schema integrity. | Quality Score &ge; 80 |
| **📧 Communication Agent** | Scans output documents for formatting errors, broken links, and tone alignment. | Quality Score &ge; 80 |

## ✨ Key Features & Quality Threshold

### 🎯 Approval Gate Logic:
- **Quality Score &ge; 80**: Approved Output (`"status": "approved"`) — Payload released to production/user.
- **Quality Score < 80**: Rejected Output (`"status": "rejected"`) — Detailed issue breakdown returned with line-specific suggestions for re-execution.

### 🛡️ Security & QA Scanner:
- **Security Vulnerability Scanner**: Detects SQL injection risks, exposed hardcoded API keys/passwords, and unsafe `eval()` calls.
- **11-Criteria Quality Evaluator**: Evaluates correctness, completeness, consistency, security, readability, and performance.
- **Offline Fallback Rule Engine**: Deterministic rule validator ensures QA verification operates even when offline.

## 🗄️ Database Schema & 7 Tables

Managed via Async SQLAlchemy & PostgreSQL:
1. `users`: System reviewers & administrator accounts.
2. `reviews`: QA evaluation records, quality scores, status, issues, and payload JSONs.
3. `review_logs`: Operational execution & audit logs.
4. `quality_scores`: Granular 11-criteria quality score breakdowns.
5. `review_rules`: Customizable rule policies and quality thresholds.
6. `review_history`: Version tracking and re-review audit trail.
7. `agent_reviews`: Agent performance tracking metrics.

## 🚀 Local Setup & Quick Start

### 1. Launch Backend Server (Port 8000)
```powershell
cd Single-Agent/review-agent/backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 2. Launch Frontend Dashboard (Port 3000)
```powershell
cd Single-Agent/review-agent/frontend
npm install
npm run dev
```

- **Dashboard**: `http://localhost:3000`
- **Backend API**: `http://localhost:8000`
- **Interactive OpenAPI Docs**: `http://localhost:8000/docs`
